Logix Catalog

Coming Q4 2026

Every FPGA board,
described once.

Logix Catalog is an open catalog of FPGA boards: which FPGA each one has, how to program it, and what its pins are wired to, from clocks and LEDs to PMOD headers. Every Logix tool uses it through Logix Engine, and so can your own tools.

Availability GitHub

One catalog behind every tool.

Users, board makers and developers describe each board in one place, and every Logix tool knows it.

Boards, described for tools and people.

The catalog says what a board is and how it's wired, so tools can start a design for it without guessing.

One file per board

Plain, readable JSON that people and tools understand alike.

Pins with meaning

Clocks, LEDs, buttons and headers by name, not just pin numbers.

Grows over time

Start with what's known about a board and add the rest later.

Open to everyone

Users and board makers add and fix boards with a pull request.

Built into the engine

Every Logix Engine release brings the catalog with it. Nothing to download.

Free for any project

Use, copy and change the data as you like. Logix Engine's open API is the intended way for tools to read it; reading the files directly works, at your own risk.

Part of Open Logix.

Every Logix tool runs on the same FPGA engine, and the engine knows every board in the catalog.
