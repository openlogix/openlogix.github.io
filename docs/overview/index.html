Project overview

What is Open Logix?

  • An open source foundation for enabling FPGA design tools.
  • Free to use and adapt, under MIT or Apache 2.0, your choice.
  • An extensible, open board model and catalog.
  • An MCP engine to build, verify and program the boards.
  • An intuitive open API for third-party tools, AI agents and automation, in any language.
  • Ready-made frontends for IDE, command-line and schematic-based design.
  • Runs on macOS, Windows and Linux.
