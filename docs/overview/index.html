Why Open Logix

Programming an FPGA board should be as easy as an Arduino.

Getting started with FPGA boards often means finding, installing and wiring up a toolchain yourself, and learning a different tool for each step. Open Logix takes that work away.

One step to install

Every tool bundles everything it needs. No separate toolchain.

Your way of working

An IDE, the command line, VS Code, schematics, remote boards, or an AI agent.

Boards just work

Logix Engine

The core of the ecosystem.

An MCP backend that gives every frontend its FPGA services, with the whole open source toolchain bundled inside.

LintBuildTestSimulateVerifyProgram the board
  • Explicit and stateless. Requests name their inputs: folders, files and the board. No project files of its own.
  • Frontends own their model. Each frontend keeps the project format and examples that fit it, from Verilog folders to block diagrams.
  • Engine first. Logic every frontend needs, such as boards, devices, Upload and build reports, lives in the engine, so no one rewrites it.
  • MCP-compatible. Logix frontends and off-the-shelf AI systems talk to it the same way.

Logix Catalog

Every FPGA board,
described once.

An open catalog of FPGA boards: which FPGA each one has, how to program it, and what its pins are wired to.

  • One JSON file per board. Clocks, LEDs, buttons and headers, checked against a published schema.
  • Built into the engine. Logix Engine ships a pinned catalog release, so every Logix tool knows the same boards.
  • Free for any project. Other tools can use the data without the engine.
  • Open to contributions. Add or fix a board in the logix-catalog repo, and every tool gets it.

Principles

Built on a few simple promises.

Every Open Logix product follows the same rules.

Easy from minute one

Intuitive to learn, quick to install, pleasant to use.

Self-contained

Everything is bundled. No separate toolchain to install.

Runs where you do

macOS on Apple Silicon, Windows x64, and Linux x64.

Free and open

MIT or Apache 2.0 licensed. Use and adapt it freely, as long as you don't call it Logix.

Spec-driven

Built from detailed AI specifications, so changes and new features come quickly.

Tested and verifiable

Extensive automated tests. Every release is built on GitHub, and builds are reproducible.

Free. Open. No catch.
