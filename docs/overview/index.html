Project overview

What is Open Logix?

  • An open source foundation for building FPGA design tools.
  • Free to use and adapt, under MIT or Apache 2.0.
  • A board catalog, and tools to build, verify and program the board.
  • Ready-made frontends: an IDE, a CLI and schematic design.
  • An open API for third-party tools, AI agents and automation, in any language.
  • Runs on macOS, Windows and Linux.
