# Open Logix website

Source for **[www.openlogix.org](https://www.openlogix.org)**, the home page of Open Logix: free, open source tools for FPGA design.

The site is static HTML in [`docs/`](docs/), published with GitHub Pages: the home page, one page per product (e.g. [`docs/ide/`](docs/ide/) at [www.openlogix.org/ide/](https://www.openlogix.org/ide/)), and one shared stylesheet, [`docs/assets/site.css`](docs/assets/site.css). Brand assets (logo and product icons) are in [`docs/brand/`](docs/brand/).

To preview locally, run `./view.sh`. It serves the site at http://localhost:8000 and opens your browser.
